# Matrix-800 ISO 20816-3 部署與設定

本專案使用感測器 FC03 `0x0032` 所提供的 X/Y/Z 速度 RMS，取三軸最大值後，
依機台的額定功率、轉速及支撐型式評估 ISO 20816-3:2022 Annex A Zone。

> 這是狀態評估與告警輔助，不是故障診斷，也不會自動停機。正式停機政策仍須結合
> OEM 限值、負載、趨勢、製程風險及現場工程判斷。

## 1. 量測前提

- 感測器的 Velocity RMS 必須是 `mm/s RMS`，register 讀值除以 100。
- 感測器的速度頻帶必須符合機台轉速：
  - RPM > 600：10–1000 Hz。
  - 120 ≤ RPM ≤ 600：2–1000 Hz。
- RPM < 120 不由本專案套用 ISO 20816-3。
- 額定功率 ≤ 15 kW 時，應選擇其他適用標準或 OEM 門檻。

若無法確認 `0x0032` 的計算頻帶，請先用校正振動源或參考儀器比對，不要把畫面上的
Zone 當作正式驗收依據。

## 2. Zone 門檻

| 設定檔 | A/B | B/C | C/D |
|---|---:|---:|---:|
| G1-Rigid | 2.3 | 4.5 | 7.1 |
| G1-Flexible | 3.5 | 7.1 | 11.0 |
| G2-Rigid | 1.4 | 2.8 | 4.5 |
| G2-Flexible | 2.3 | 4.5 | 7.1 |

所有數值單位均為 mm/s RMS。程式中的唯一門檻來源位於 `iso20816.py`。

## 3. 安裝到 Gateway

```bash
sudo mkdir -p /opt/matrix800-iso20816
sudo cp -a matrix800-iso20816-gateway/. /opt/matrix800-iso20816/
cd /opt/matrix800-iso20816

python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

在 `sensor_reader.py` 設定實際使用的 `/dev/ttyUSB*`，並依原專案文件確認 NPU
runtime、delegate 與模型。

首次測試：

```bash
sudo .venv/bin/python app.py
```

開啟 `http://<gateway-ip>/settings`，對每個測點設定：

- 額定功率 kW：優先使用銘牌資料，不使用瞬時電流代替。
- RPM：用於選擇 RMS 頻帶。
- 支撐型式：Rigid 或 Flexible。
- Group：通常選 Auto；只有經工程確認才手動覆寫。
- Confirmation time：跨越 Zone 後需持續多久才切換，預設 10 秒。
- Recovery hysteresis：恢復到較低 Zone 時需額外低於門檻的距離，預設 0.2 mm/s。

儲存後到 `/metrics` 查看 ISO Zone、三軸最大值、頻帶、門檻與建議動作。

## 4. 開機自動執行

```bash
sudo cp deploy/matrix800-iso20816.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now matrix800-iso20816
sudo journalctl -u matrix800-iso20816 -f
```

## 5. API

即時快照：

```bash
curl http://127.0.0.1/api/metrics
```

每個 port 的回傳資料會包含 `iso20816`：`profile_code`、`frequency_band_hz`、
`velocity_rms_mm_s`、`max_axis`、`boundaries_mm_s`、`raw_zone`、穩定化後的
`zone`、`pending_zone`、`alarm` 及 `action`。

設定檔儲存在 `machine_profiles.json`，由網頁或 API 寫入時採用原子置換，避免斷電時
留下半份 JSON。
